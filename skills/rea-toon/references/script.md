# 剧本和分镜脚本

`analyze` 和 `series` 跑完会自动出两份文件，各有 HTML 和 PDF；也可以单独跑 `rea-toon script work/<名字>`
（单集目录或整部剧目录都行）。PDF 用本机 Chrome 无头打印，没有 Chrome 就只出 HTML（`REA_TOON_CHROME` 可指定浏览器）。
- **剧本** `pages/script.html` / `script.pdf`（纯文本 `script.md`）：标准短剧剧本格式，给人读剧情。
  人物表（小头像 + 身份），逐集梗概，逐场：`1-2　日　内　游乐场服务中心大厅　（回忆）`、人物、△动作、台词、【字幕】。
  台词写成 `纪舟野：（神情）您放心，只要……`，画外 `（OS）`、心里话 `（内心OS）`、`旁白：`；
  一段话被切成几镜的合成一句（中间的动作挪到后面）。OS 只给不在这场戏里的声音（广播、电话那头）：
  人在场、只是这一镜没拍到他，剧本里照常写（分镜脚本按镜头写，那里仍标 OS）。
  台词里字母夹数字的串、7 位以上数字（招牌、电话号码被读成了字幕）直接去掉；只有一两个镜头、台词没说完就接下一场的碎场
  并进下一场，相邻同场次头的场合并。
  每集两次纯文本模型调用（有缓存，重出不花钱；没配模型就用拆解原文）：
  ① 台词补标点（字幕本身没有；只许加标点，改了字的那句不用）；
  ② 剧本润色：把逐镜拼成的△动作改写成编剧写法（去镜头语言、去重复，原文没有的情节不许编），
  定每场的日/夜、内/外和简洁地点名，给龙套起剧本里的称呼（"前台员工"）；同一个龙套 id 其实是几个人时按句起名
  （"广播员""店员甲"）；规则没去掉的乱码（"Atantee"）让模型删，只许删字、最多删 6 个汉字，改了字的不用。回复里缺的部分保留原样。
- **分镜脚本** `pages/storyboard.html` / `storyboard.pdf`：漫剧常用的生产格式，前面是角色设定（头像 + 造型图 + 身份 + 外貌），
  然后每场一张表，一行一镜：镜号（必保镜左边红线，下面是钩子/爽点等戏剧作用）、缩略图、景别（加俯拍/仰拍等机位）、
  画面描述（加出镜角色）、台词 / 旁白 / OS、音效（原片音轨里听出的叮/嗖/啵，只留卡在贴纸、花字、标注出现时的和特别响的，括号里是卡在什么上；
  卡在字幕出现时的多半是人声起音，不列；仍是提示，不是逐条核对过的）、
  动效（全动 / 局部动 / 静图推拉 + 运镜 + 闪白等特效）、时长。
- 角色图：头像用 YuNet 在他出镜的近景里找脸（多人时按拆解里的左右位置认，字幕先抠掉），造型图取他单独出镜的中景，
  避开回忆场。图在 `characters/<id>_face.jpg`、`<id>_look.jpg`，分镜缩略图在 `characters/shots/`。
- 质量取决于拆解：说话人、角色合并、分场错了，剧本跟着错，先审 pages/breakdown.html。
